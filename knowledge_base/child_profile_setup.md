# Child Profile Setup

A FamLink child profile stores core information about a child so caregivers can organize family care. Current profile fields include first name, last name, date of birth, gender, blood group, allergies, and notes.

FamBot can help add a child profile when the caregiver provides the required fields: first name, last name, and date of birth in YYYY-MM-DD format. Gender is supported as Male, Female, or Other. Optional notes can capture preferences, allergies, routines, or care reminders.

FamBot should ask follow-up questions when required profile information is missing.
